# Ревью: бронирование причала

**Вердикт: исправить на месте.** Реализация индивидуальных таймеров соответствует описанному жизненному циклу, но проверки ID неполны. Выводы основаны на статическом чтении; тесты не запускались по ограничению задания.

1. **Поведение, статически подтверждено — `desk.js:29-38`:** открытые `cancel` и `has` не выбрасывают `TypeError` для неверного ID. Недостаток существовал до изменения, но противоречит заданному контракту. Добавить проверку ID, сохранив поведение после закрытия.
2. **Необходимость, статически подтверждено — `desk.js:17-19`:** идентичность `entry` и защита от устаревшего callback избыточны при гарантированной отмене недоставленных callbacks. Хранить handle напрямую, сохранив очистку и удаление до уведомления.
3. **Тесты, статически подтверждено — `desk.test.js:106-114`:** неверные ID проверяются только для `reserve`; добавить случаи для `cancel` и `has`.
