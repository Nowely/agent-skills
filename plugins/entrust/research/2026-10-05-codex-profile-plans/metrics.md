# Metrics

## Run evidence

- n = 3 plan cards, same task fixture and policy files.
- Requested coordinators: 3 x gpt-6-luna at xhigh.
- Requested blind judge: 1 x gpt-6-astra at xhigh.
- Effective model receipts, token usage, elapsed time, and monetary cost: unknown.
- No task execution or worker-launch call was requested by any arm; no source files were changed during plan generation.

## Blind classification

The Astra judge classified A as balanced (75%), B as speed-oriented (90%), and C as quality-oriented (55%). It found the distinction between balanced and quality weak and flagged C's coordinator choice and review split.

## Deviations and limitations

- The plan-only arms were generated by fresh native Luna calls, but the coordinator did not receive an explicit statement that the test harness's current model was Luna. Exact coordinator identity therefore cannot be judged as a runtime capability from this run.
- The primary test measures approval-card composition, not findings, task quality, actual latency, or savings.
- The comparison is one task fixture and three cards; it does not establish general model rankings.
