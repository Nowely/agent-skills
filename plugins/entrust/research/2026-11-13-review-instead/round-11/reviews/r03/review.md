**[P1] Старые категории не используют выбранную локаль** — `src/category-labels.js:4-9`

`notes`, `photos`, `music` и `archives` по-прежнему переводятся при импорте, когда локаль равна `en`. После `setLocale("ru")` оба публичных способа чтения возвращают для них английские подписи, а `saveSelection("notes")` сохраняет `Notes` вместо `Заметки`. Это существовавший ранее дефект, но задание явно требует соблюсти контракт README для всех категорий. Новые геттеры исправляют поведение только для двух добавленных категорий. Нужно вычислять подписи всех категорий при чтении и проверить обе функции после смены локали, включая сохранение старой категории и последующую смену локали.
