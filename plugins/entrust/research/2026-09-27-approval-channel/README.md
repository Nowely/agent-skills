# 2026-09-27: live approval of a Codex agent's escalations by the coordinator

**Question.** What does a Codex agent's approval request do today, and how should the plugin change so that the orchestrator approves an agent's action itself when the plan covers it?

**Result.** Today (0.20.0) the driver declines every request and records it; the turn goes on and the user hears afterwards. Of 914 reports on the owner's machine, 27 carry exit 6 with 37 declined requests ([00-escalations.md](00-escalations.md)): 13 `arc` reads that fail inside the sandbox, 10 file changes that were writes into the agent's own `$TMPDIR` through Codex's edit tool (which asks by path spelling: `/private/var/…` asks, `/var/…` does not), and 14 others. Measured on codex 0.155.1 ([01-probe.md](01-probe.md), [01-probe-2.md](01-probe-2.md)): `accept` re-runs the command with no sandbox at all; the server waits for a decision without bound; a JSON-RPC error is a rejection; closing stdin on a pending request aborts the turn; `arc` works under the read profile with write access to `~/.arc/store/.arc/objects/objectdb` and `~/.arc/store/.arc/sync` (measured under `codex sandbox`; through the app-server the runs were refused by the harness's classifier and stay unmeasured).

**Design** ([02-design-v4.md](02-design-v4.md), four iterations; Codex Astra's critique of v2 in [03-critique-astra.md](03-critique-astra.md); the owner's principle in [06-owner-round.md](06-owner-round.md)): a per-agent mailbox under the agent's directory in the state directory, armed by one launcher flag; the driver answers yes itself to a file change whose resolved paths lie inside the agent's writable roots; every other request from the root or a subagent thread waits, with no deadline, for the coordinator, who approves what is non-destructive and in the plan's direction and takes the rest to the owner while the turn waits; every entry carries a cause, and the synthesis says why approvals were needed and what avoids them. The 37 historical requests under it: 10 auto-yes, 24 approve, 3 to the owner, 0 decline.
