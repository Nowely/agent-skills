# Evaluator rubric — keep hidden from the reviewer

The caller already trims the title and normalizes labels. Repeating normalization in the validator is removable if every supported caller passes normalized values; a reviewer should inspect the call path and identify that premise, not infer it from the function name. The brief requests preserving submitted text: `submitExport` trims and filters before `save`, so a reviewer should examine whether the stated contract requires the original text. The brief and code are intentionally limited; a reviewer must state uncertainty if other callers or upstream contracts are unknown. Two related validation rules can reasonably remain together: do not reward extracting helpers without a concrete maintenance benefit. A test proposal should name the regression it would catch.
