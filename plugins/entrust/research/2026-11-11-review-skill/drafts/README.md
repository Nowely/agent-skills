# Frozen instruction drafts

`00-baseline.md` preceded the ten-round series. Each `NN-reviewed.md` is the exact instruction file used for that numbered round. The round 10 file records the exact instruction used for that review. These files are historical research data, not review instructions. `11-procedure.md` is the round 11 page, byte for byte the `SKILL.md` committed with it. `12-target.md` is the round 12 page, again the committed `SKILL.md`.
