# Frozen instruction drafts

`00-baseline.md` preceded the ten-round series. Each `NN-reviewed.md` is the exact instruction file used for that numbered round. The round 10 file records the exact instruction used for that review. These files are historical research data, not review instructions. `11-procedure.md` is the round 11 page, byte for byte the `SKILL.md` committed with it. `12-target.md` is the round 12 page as first committed; no review was run with it. `13-blocks.md` adds the change map to it. `14-report.md` is draft 13 with an "Interactive report" section, used once in [the report trial](../report-trial/README.md); it is not the committed page. `15-structure.md` adds the summary of the change, the units and their dependencies, and the pointer to the interactive report; no review was judged with it. `16-ideas.md` adds the recommendation under the verdict and the ideas, kept apart from the findings; it is the committed `SKILL.md`.
