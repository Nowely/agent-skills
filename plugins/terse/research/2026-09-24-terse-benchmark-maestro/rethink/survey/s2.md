**Method.** Every document was fetched with `curl` as raw Markdown (`raw.githubusercontent.com/OWNER/REPO/HEAD/README.md`
or, for the MCP site, its own `.md`-suffixed source route) or, for GitHub/npm/VS Code vendor docs, the
Markdown/MDX source behind the rendered page (found via each page's live "Edit this page" link, then
fetched from `raw.githubusercontent.com`). Nothing was rendered or summarized. Saved under
`survey/fetched/`. Word counts are `wc -w` on the saved bytes. Headings are `#`-style Markdown lines
outside fenced code (Linux and git use ReST underline headings instead — noted per-document). Tables are
Markdown pipe-rows (checked manually where a loose regex first missed one). Code blocks are matched
triple-backtick/tilde pairs. Images/badges count both Markdown `![]()` and raw `<img>` tags; a badge is a
status/version/build/social-count image (shields.io and equivalents); anything else (logo, screenshot,
sponsor graphic) is a non-badge image. Usage signal for slice 3 is `stargazers_count`/`forks_count` from
`api.github.com/repos/OWNER/REPO`, fetched this run and saved in `fetched/_star-scan.tsv` alongside a
14-repo scan used to pick the 8. Slice 4 has no comparable usage signal — see that section's header.

## Slice 3 — THE MOST USED REGARDLESS OF GENRE

**Selection.** I scanned 14 candidate developer tools' star counts this run (saved in `_star-scan.tsv`)
and took the top 7 by GitHub stars, plus one deliberate 8th: `git/git`, whose star count (63,295) is far
below the other 7 but whose real-world use is close to universal and simply isn't GitHub-star-mediated
(most people get git from an OS package manager, never visiting github.com/git/git). I kept it in rather
than drop it, per the brief's "where a much-used document does something badly, say so, rather than
ranking a pretty unknown above it" — omitting it would have hidden the single starkest example in the set.
`vuejs/vue` is Vue 2, marked End-of-Life by its own README; Vue 3's repo, `vuejs/core`, has far fewer stars
(54,423 vs. 212,823 — also scanned, not fetched) so `vuejs/vue` is the fairer "most-used" pick, but the EOL
status is itself part of what its README does, noted below.

   directly after the identity paragraph, that 2 of 8 documents have — tensorflow (200,273 stars, a code
   block: `pip install tensorflow`) and ohmyzsh (189,898 stars, two 3-row tables of curl/wget/fetch
   one-liners). Ranked first because both holders sit in the top usage tier and this is purpose.md's item 3

2. **A role-based router.** A "Who Are You?"-style section whose purpose is to send different reader types
   straight to their own next step, placed right after Quick Start, that 1 of 8 documents (linux, 249,971
   stars) has as a named, explicit pattern — 9 role sub-sections, each its own heading and bullet list.
