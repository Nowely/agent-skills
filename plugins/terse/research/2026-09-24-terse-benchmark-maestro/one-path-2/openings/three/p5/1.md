# ![Maestro](assets/banner.png)

**Maestro** helps you build LLM apps and agents that hold up in production. Demos forgive what production doesn't: unstructured prompts, a stuffed context window, too many tools, no error handling, no evaluation, no cost ceiling. Maestro gives your coding tool 24 slash commands that find these weak spots in your app and fix them.

- **Built on LLM engineering practice.** The commands draw on principles and guides from prompt structure to guardrails, so your coding tool follows a method instead of improvising.
- **Advice that fits your stack.** Maestro keeps your models, budget, latency limits and compliance needs in one project file, so the commands start from your constraints, not generic guidance.
- **Fits your coding tool.** The same commands for Claude Code, Cursor, Codex, Gemini CLI, Kiro, Trae, OpenCode, Pi and Antigravity, plus an extension for VS Code and a server for other AI clients, so teammates on different tools share one set.
- **Picks up where you left off.** Session notes keep what you did, decided and left open, so the next session starts there instead of from scratch.
