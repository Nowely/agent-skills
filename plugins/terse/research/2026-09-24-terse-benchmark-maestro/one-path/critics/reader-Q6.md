The extension writes 25 SKILL.md files into ten agent folders and adds its MCP server to the workspace MCP config on every start. From the second start onward, it rewrites .vscode/mcp.json with only Maestro’s entry. Enabling Zero-Defect writes precision rules into CLAUDE.md (and a corresponding rule file for Cursor or Antigravity). Each @maestro command is logged under .maestro/.

Section heading: How it works

Quote: “On every start it writes the 25 `SKILL.md` files into ten agent folders in your workspace (`.agents`, `.claude`, `.cursor`, `.gemini`, `.codex`, `.kiro`, `.trae`, `.trae-cn`, `.opencode`, `.pi`) and adds its MCP server to the workspace's MCP config; from the second start on it rewrites `.vscode/mcp.json` with Maestro's entry alone.”

Quote: “Turning that on writes the precision rules into `CLAUDE.md`, and also into `.cursorrules` in Cursor or a rule file in Antigravity.”

Quote: “In VS Code, `@maestro` runs `/diagnose`, `/evaluate`, `/fortify`, `/refine`, `/chain` and `/compose` in checked phases, adds the precision rules to every request while Zero-Defect is on, and logs each command under `.maestro/`.”
