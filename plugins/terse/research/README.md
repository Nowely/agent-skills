# Research: terse

Every measurement the `terse` plugin's rules rest on, and the runs that produced them. Nothing here is
installed with the plugin or read at runtime. Each directory has its own README with the result; this is
the index. entrust's runs have [their own index](../../entrust/research/README.md).

| Directory | Question | Result |
|---|---|---|
| [2026-09-10-chain](2026-09-10-chain/) | does a four-pass audit-and-revise chain make one README truer and easier to answer from? | 3/6 → 6/6 on six reader questions, one trial each (p = 0.25, not distinguishable from chance); two of six failures were false claims a prose rewrite would have kept; on ten seats, three published writing standards lost to two unguided controls, and the draft block that became `writing-rules.md` beat both controls on the readability axis (one seat of its two; the other fell below them) |
| [2026-09-11-terse-survey](2026-09-11-terse-survey/) | what does the field already know? | three rounds, 37 agents, 108 ranked practices; the plugin's own numbers measure model answerability, not human improvement; no arm ever ran without the document |
| [2026-09-11-calibration-bank](2026-09-11-calibration-bank/) | which forms of writing does this one reader prefer, measured blind? | a 139-item bank that passed its blind checks (tone 30% → 73% single-factored after a one-span rule); the run on the owner stopped at 42 answers with one factor separated at 0.05, one undetermined, one unjudgeable, and five objections none of which was an item — the skill was retired |
| [2026-09-11-markup-round-0](2026-09-11-markup-round-0/) | can the method produce a README its owner would send as it is? | nine rounds; regressions per round 1, 2, 1, 0, 6, 5, 10 — every one a lifecycle sentence written from reading, not running; an eleven-agent wave found 41 defects after six rounds; the first naive reader said "not yet" for content, not phrasing; round 09 says less and awaits the owner's read |
| [2026-09-12-skill-review](2026-09-12-skill-review/) | can a fresh agent execute the skill from its text? | 9,650 words to the first action and 19 gaps; after restructuring, 677 words; the dry-run prompt is the ruler for skill text |
| [2026-09-22-terse-process](2026-09-22-terse-process/) | can `terse` judge a text before touching it, hand a rewrite to its owner, iterate without harming, and collect practice with a method? | fifteen waves; the 25 recorded regressions autopsied (declared-check execution reaches 4, the ledger 2, a brief rule 7, new evidence 12); two designs critiqued and not implemented; then the seed, the executed check and the verifier implemented on a branch and the pages run live on the plugin's own README — audit 5/7 against 0/7 without the document with 11 refuted claims, a bake-off and three rounds with regressions 3 → 0 → 2, all at level 3, the verifier sending rounds back five times before the freeze; the task gate reached once; the cap of four reached and round 04 handed over; E5 fixed, E6–E14 recorded, D1–D13 proposed; then the owner rejected round 04 for its shape, the pages gained the shape agreement, lens 7 and the qualification signal, `rethink` ran on the same README — 39 documents, ten structures, three critics, three skeletons read by the owner — and the rewrite from the agreed skeleton reached regressions 1 → 0 → 0 in three rounds; round 04 was sent as it is on 2026-09-24 and is the plugin's README; D1–D24 re-run on HEAD and entered in `ISSUES.md` as E15–E38 |
| [2026-09-24-terse-benchmark-maestro](2026-09-24-terse-benchmark-maestro/) | on a popular repository whose README counts as good, does a README written with the skills beat a bare agent's, and how far is either from the repository's own? | on the owner's blind read the repository's own README first, the skills' second at parity with it, the bare agent's third for formatting and wordiness; the sequential path took 6 h 38 min against the bare agent's 14; rebuilt as one path — one writer, every critic at once, one repair — it wrote the same README in 70 minutes, then in 93 with a harness per truth critic |
| [2026-09-26-terse-light-trial](2026-09-26-terse-light-trial/) | does the one path, light, write a better README than a bare agent for another project, the terminal tool dust? | no: the owner ranked the bare agent's text first, ours second, the original third — rules applied as requirements had cut the demo, the "du, written in Rust" pitch and the install routes; the rules became two requirements and advice, and the writer starts from the text's world |
| [2026-09-26-terse-second-checks](2026-09-26-terse-second-checks/) | after the rules became advice: the same README against the same bare text, and a text of another kind, the comments of dust's directory walker | the owner named ours "much better", not yet selling — the case for choosing it and the options reference missing; the comments have no owner read, their question readers answered 3 of 3 and the code stayed byte-identical; the writer applied 35 of 36 substantive findings, the truth critics' qualifications among them |
| [2026-09-26-writing-replication](2026-09-26-writing-replication/) | on a second machine's sessions, how does the user react to the texts the assistant writes, and does the first run (#20) hold? | 144 sessions, 323 feedback episodes from 51 dialogues, 29 principles (20 strong, 9 moderate) and one candidate after a 500-agent stress test and a judge; against #20: 9 confirmed, 12 partly, 0 contradicted, 2 not found, 15 new; posted as a comment on #20; the raw corpus stays off the repository; the `clarity` trigger measured across three descriptions, the final one chosen in 78 of 78 clean runs where it fits and 32 of 33 counted runs in the owner's environment, in none where it does not |
| [2026-09-28-critical-thinking](2026-09-28-critical-thinking/) | which traits of critical thinking would make the agent's texts and conclusions more useful, and on what evidence? | four candidates for 0.4.0 — the observation that would change a recommendation, checked; a disputed fact rechecked at its source; a brief without a preferred verdict; a factual premise checked — from 323 feedback episodes and the measured literature; generic calls to be careful rejected as null or harmful; piloted on 100 blind-written cases with a content eval harness: none passed — K1 and K2 had no room, K3 and K4 stayed within the range of the unchanged pages run twice, so no effect was detected |

What carried over into the plugin: the rules and their measurements, in
`plugins/terse/plugin/references/rules.md` and `measurements.md`, and one script with its self-test,
`plugins/terse/plugin/skills/rewrite/scripts/sections.mjs`.
The sequential method's pages and scripts — the stages, the loop, the ledger, the rounds — shipped until
`terse@0.1.1` and left the plugin in 0.2.0. What did not: `calibrate`, kept at
`2026-09-11-calibration-bank/tool/` with its result.
