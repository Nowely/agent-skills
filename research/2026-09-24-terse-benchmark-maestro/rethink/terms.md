**The thesis the words serve.** Purpose.md §1 says Maestro gives an AI coding agent 25 skills by three routes.
Every route claims that Maestro's parts are things the reader's coding agent already runs: skills in its skills
folder, commands typed in its chat, and an MCP server like any other. By stage 2's rule, the README calls those
parts by the agent's words: skill, skills folder, slash command, MCP server and MCP client.

**Readers** (purpose.md §2)
- A builds LLM features, agents or pipelines inside an AI coding agent. They know slash commands, may not know
  MCP or skills folders, and have not picked a route.
- B already uses the extension or the MCP server, and comes for the command list, the source or to contribute.

**Rules the table implies**
1. "Agent" never stands alone. "Coding agent" means Claude Code, Cursor, Codex and the like, and the agents the
   reader builds are "the agents you build" (rows 4, 6).
2. "Workflow" means only the reader's AI workflow. It never means their development process or a GitHub
   Actions workflow, and no heading uses it (row 3).
3. "Command" means only the 24 commands. A line typed in a terminal is "run in your terminal" (row 11).
4. "Memory" means only session memory. The MCP wave note says "held by the running server" (rows 34, 40).
5. Every cost or token figure carries "~" or "estimate" and refers to Maestro's own command runs (rows 42, 43).
6. "Provider" keeps only its LLM-vendor sense, and appears only inside command descriptions (row 6).

## The five decisions I am least sure of

1. **Defining "workflow" rather than renaming it (row 3).** The owner fixed the tagline, and it puts the
   ambiguous word first. A reader who parses "Workflow fluency for AI coding agents" as a development
   methodology, which is the genre's subject (superpowers:3), may never reach the definition in the next
   sentence. **What would settle it:** a cold read. Give five readers who match purpose.md §2 the title, the
   tagline and the first sentence, and ask what Maestro improves: (a) how your coding agent works on your
   code, or (b) the LLM feature you are building. Keep the decision if at least 4 of 5 answer (b). Otherwise
   take the tagline to the owner, since changing it is theirs to decide.
2. **Renaming "memory layer" to "session memory" (row 34).** This renames the owner's own 2.0 headline
   (answers-01 §5.5), and "session memory" has a misreading of its own: memory inside one chat session.
   **What would settle it:** the owner's word on the rename, plus the same cold-read probe run on "session
   memory", "memory layer" and "cross-session memory". Ask "does this give the agent you are building a
   memory?" and keep the name that draws the fewest yes answers.
