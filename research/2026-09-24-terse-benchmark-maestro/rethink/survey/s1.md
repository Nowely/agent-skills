# Survey, stage 1 of rethink — sharpdeveye/maestro's README

**Slices:** (1) the exact genre — READMEs of skill/command libraries for AI coding agents shipped as
skill files, an MCP server, or an editor extension; (2) the same structural position — a root README
that also has a Marketplace or npm page and must front all of them without repeating them.
**Date:** 2026-09-24. **Surveyor:** s1 (Sonnet).

**Documents fetched:** 12 distinct repositories — 7 for slice 1, 5 for slice 2 — every README fetched as
raw markdown via `raw.githubusercontent.com/OWNER/REPO/HEAD/README.md` (or the file's true path where the
root file is a stub, see biomejs/biome below), saved under `survey/fetched/slice{1,2}/`. Usage signals
fetched from `api.github.com/repos/OWNER/REPO` (stars, forks) and, where the README names an npm package,
`api.npmjs.org/downloads/point/last-month/PACKAGE`; both saved under `survey/fetched/`. The target
repository (sharpdeveye/maestro), its README, its forks/mirrors, its npm and Marketplace pages, and
maestroskills.dev were not fetched, cited, or read; the snapshot at `/var/folders/mf/9v804k_57lq30kwtlr7468xr0000gn/T/terse-bench/snapshot` was not read either, per the brief.

**Failures:**
- `sourcegraph/cody` — 404 on both the raw README and the GitHub API (`{"message":"Not Found"}`); the repo
  does not exist at that path. Dropped from slice 2 and replaced with `cline/cline`.
- `biomejs/biome`'s root `README.md` is not a failure but is worth flagging here: fetching it returns 35
  bytes of plain text, `./packages/@biomejs/biome/README.md` — a relative path, not a markdown link and
  not something GitHub resolves as a redirect. The real content lives at that path and was fetched
  separately (both files are saved; the stub is cited under slice 2's "Not to copy").

**Method notes:** word counts are whitespace-token counts of the whole saved file (title, badges, link
syntax and all), so they are comparable to each other but larger than a prose-only count. "First N words"
strips images, badges, HTML tags and heading lines, then takes the first N whitespace tokens of what's
left, verbatim. Sub-block markers (`###`+ headings, standalone bold lead-ins, fenced code blocks) are
reported as three separate counts, not summed — a fence nested inside a `###` subsection is not a
second, independent split of the same section.
