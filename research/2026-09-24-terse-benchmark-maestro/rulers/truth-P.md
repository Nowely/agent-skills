## Refuted claims, ranked by what a reader who acted on them would lose

1. **The HTTP transport: lines 135-138 and 141 (rows 53, 54).** Each server process answers exactly one request. The client's next message, the `notifications/initialized` it sends right after connecting, and every request after it get HTTP 500. No MCP client can hold a session. A reader who acts on this loses the whole HTTP deployment path, meaning a shared or remote server, and gets only an unexplained 500. Meanwhile the endpoint still runs one unauthenticated tool call per start (row 57).
2. **The core skill: lines 90 and 14 (rows 40, 3).** Neither the `@maestro` participant nor the MCP prompts include `agent-workflow`, and /teach-maestro never loads it. In VS Code chat, every command runs without the context protocol, design principles and slop test that the README credits to the core skill, while the model is told to "Invoke /agent-workflow", which it cannot do.
3. **MCP waves: line 155 (row 65).** An MCP wave carries generic phase prompts, never the command's own instructions. A reader who runs /fortify "as a staged wave" gets a generic audit→apply→verify loop without /fortify's five layers, and nothing signals that anything is missing.
4. **Logging: lines 177, 99 and 100 (rows 88, 44, 45).** A wave cancelled between or during phases leaves no audit or decision entry, and a cancelled single request is logged as completed. /reflect's completion and abandonment rates, the numbers it exists to report, are therefore wrong exactly for the runs users abandon.
5. **npm publishing: line 244 (row 120).** The npm publish workflow fails at its build step. A maintainer who pushes an `mcp-v*` tag ships nothing, and npm keeps the previous version.
6. **Token counts: line 103 (row 48).** The logged input count covers only the context slice, and is 0 when there is no context file. /reflect's cost totals therefore leave out the instruction text every command sends, a larger gap than "rough estimates" suggests.
7. **The dependency list: line 177 (row 86).** Whether the list is sent depends on the order files were indexed in. Some requests silently get no file-dependency context.
8. **`npm run dev`: line 241 (row 117).** The command does not rebuild the sidebar the extension loads. A contributor's sidebar edits do not appear until `npm run build:webview`.
